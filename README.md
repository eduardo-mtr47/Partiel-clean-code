# Partiel-clean-code Ecommerce Pricing

url projet git : https://github.com/eduardo-mtr47/Partiel-clean-code
## Initialisation du projet
```bash
cd ecommerce-pricing
npm install
```
## affichage de la facture 
```bash
node index.js
```
## lancer les tests
```bash
npm test
```
## coverage des tests 
```bash
npm test -- --coverage
```
